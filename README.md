# Configurable UART Communication Controller
• Designed a parameterized UART controller supporting 5–9 data bits, Odd/Even/None parity, configurable stop bits, 16×
oversampling, majority-vote sampling, and 2-FF RX synchronization.
• Implemented 16-deep asynchronous TX/RX FIFOs with pointer-based control and developed a self-checking testbench with
framing, parity, and overflow error injection
